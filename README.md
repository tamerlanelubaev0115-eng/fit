# FitPulse 🍏💧🚬👟

> Автономное веб-приложение (PWA) для персонального трекинга привычек, рациона, никотина, шагов и прогресса похудения в стиле **Apple Health / Vercel**.

Оптимизировано под мобильный Safari (iPhone — добавление «На экран Домой» как нативное приложение).

---

## ⚡ Особенности

- 🍏 **Трекинг питания:** название блюда, калории, быстрые теги, авто-время.
- 💧 **Трекинг воды:** выбор напитков (*Вода, Сарыагаш, Чай/Кофе, Кола Zero*) и 3 круглые кнопки быстрого объема (0.5 стакана / 1 стакан / 1 литр).
- 🚬 **Никотин:** быстрый клик `+1 Стик` и `+1 Сигарета` с авто-фиксацией времени.
- 👟 **Шагомер:** дневная цель, расчет километров и сожженных калорий.
- ⚖️ **Цель по весу:** стартовый вес, текущий вес, целевой вес, прогресс-бар и подсчет сброшенных килограммов.
- 🟩 **GitHub-style Activity Calendar:** сетка дней за 7 недель с цветовой градацией активности и возможностью открыть/дополнить любой день.
- 📦 **100% автономность:** всё работает из одного файла `index.html` на чистом HTML5 + CSS3 + Vanilla JS, сохраняется в `localStorage`, с возможностью экспорта/импорта в JSON.

---

## 🚀 Запуск локально

```bash
# Установка зависимостей (для локального сервера)
npm install

# Запуск сервера
node server.js
```

Приложение будет доступно по адресу: `http://localhost:3000`  
Или по IP в локальной сети на iPhone: `http://<ТВОЙ-IP>:3000`

---

## 📱 Как добавить на экран iPhone:
1. Откройте сайт в Safari.
2. Нажмите кнопку **«Поделиться»** (иконка квадрата со стрелкой вверх).
3. Выберите **«На экран «Домой»» (Add to Home Screen)**.
